# My-terminal-dotfile
Aesthetic &amp; minimal Linux terminal configuration
![Terminal Preview](assets/preview.png)
A personal Linux terminal configuration focused on simplicity, aesthetics, and productivity.

Nexus Dotfiles brings together my customized terminal environment using Kitty, Zsh, Powerlevel10k, and Fastfetch.

Features

Kitty – Fast, GPU-accelerated terminal emulator.

Zsh – Powerful and customizable shell.

Powerlevel10k – Customizable shell prompt.

Fastfetch – Lightweight system information tool.

Automated Installation – Simple setup using install.sh.

Symlink-based Configuration – Easily manage and update configurations.

Requirements

Make sure the following applications are installed:

Kitty

Zsh

Powerlevel10k

Fastfetch

Installation

1. Clone the repository

git clone <your-repository-url>
cd Nexus-Dotfiles

2. Run the installer

chmod +x install.sh
./install.sh

The installer will:

Check required configuration files.

Back up existing configurations.

Create symbolic links.

Set Zsh as the default shell when necessary.

3. Restart your terminal

Open a new terminal session to apply the configurations.
